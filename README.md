# Personal Finance Tracker 💰

Hi! I'm Saranya, and this is my Python-based Personal Finance Tracker project.  
It is a simple command-line application that helps users manage their income and expenses in an organized way.

---

## 🚀 What This Project Does

This project helps you:

- Add income and expense transactions
- Store all data in a CSV file
- View transactions between selected dates
- Calculate total income, expenses, and savings
- Display financial summaries
- Visualize income vs expense trends using graphs

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- CSV Module
- Datetime Module

## ⚙️ How to Run This Project

### Step 1: Clone the repository
```bash
git clone https://github.com/your-username/finance-tracker.git
```

### Step 2: Move into the folder
```bash
cd finance-tracker
```

### Step 3: Install required libraries
```bash
pip install pandas matplotlib
```

### Step 4: Run the program
```bash
python main.py
```
